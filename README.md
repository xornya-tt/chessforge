# ChessForge 3D

Нативные офлайн-шахматы для **Anbernic RG35XX Plus** и **MustardOS 2606.0 Andromeda**. Игра написана на C++17 и SDL2: ей не нужен браузер, интернет или телефон.

## Что готово

- Полные шахматные правила: рокировка, en passant, превращение, шах, мат, пат и правило 50 ходов.
- `Stockfish` через UCI из `bin/stockfish`. Если Stockfish отсутствует, включается встроенный minimax-бот.
- Уровень противника от 400 до 3200. Значения 1320–3190 передаются Stockfish через `UCI_LimitStrength` и `UCI_Elo`.
- Настоящая перспективная 3D-сцена, камера с поворотом и наклоном. Рендер программный, поэтому не зависит от OpenGL-драйвера прошивки.
- **3D-фигуры** с настоящей формой: точёные пешка, слон, ферзь и король, ладья с зубцами, конь с головой лошади. Они затенены, имеют контур и тень на доске, поэтому не сливаются ни с клетками, ни друг с другом. Выбранная фигура приподнимается.
- **Курсор, который не сливается с доской**: цвет рамки подбирается по реальному цвету клетки (контраст не ниже 3:1 на любой теме и любой своей палитре) и обводится тонким чёрным/белым кантом.
- **Режим на двоих** на одном устройстве, доска разворачивается к тому, чей ход. У каждого игрока свой запомненный курсор.
- **8 языков интерфейса**: English, Русский, Українська, Deutsch, Español, Français, Italiano, Português.
- **Настройка кнопок в самой игре**: Y → CONTROLS.
- 2D-режим, сохранение FEN, автосохранение и отмена хода.
- Четыре готовые палитры: Oak, Violet, Forest, Mono, и четыре **темы Lichess**: `LICHESS BROWN`, `BLUE`, `GREEN`, `PURPLE` (цвета клеток досок Lichess в тёмном оформлении Lichess). Чтобы доска выглядела как на Lichess, поставь `TEXTURE → FLAT`. Цвета Brown (`#f0d9b5`/`#b58863`) и Blue (`#dee3e6`/`#8ca2ad`) сверены с источниками, Green и Purple близки к оригиналу, но заданы по памяти; при желании подправь их в `LichessThemes` в `src/main.cpp`.
- Полностью настраиваемая палитра: свой цвет светлых клеток, тёмных клеток, акцента и фона — RGB от 0 до 255.
- Пять процедурных фактур, доступных в 2D и 3D: `Flat`, `Wood`, `Marble`, `Carbon`, `Felt`.

## Настройка цветов и фактур на консоли

1. Запусти игру и нажми **Y**.
2. В `THEME` поставь `CUSTOM`, либо открой любой RGB-пункт — игра сама переключится на `CUSTOM`.
3. В `TEXTURE` выбери фактуру доски.
4. Выбери `LIGHT RGB`, `DARK RGB`, `ACCENT RGB` или `BACK RGB`.
5. Нажми **A**: `Up/Down` выбирают канал R/G/B, `Left/Right` меняют значение на 5.
6. Нажми **A**, чтобы сохранить цвет. Настройки сохраняются автоматически.

Можно также вручную задать палитру в `<SD>/MUOS/application/ChessForge3D/saves/settings.cfg`. Готовый пример неоновой карбоновой темы — [`themes/neon-carbon.cfg`](themes/neon-carbon.cfg).

## Язык, режим на двоих, кнопки

**Y → LANGUAGE** (влево/вправо) меняет язык сразу. При первом запуске язык берётся из системной локали (`LANG=ru_RU...`), иначе английский.

**Y → GAME MODE → TWO PLAYERS**: оба игрока ходят с одного устройства по очереди, Stockfish не используется. Пункт **BOARD TURN** выбирает, разворачивать ли доску к тому, чей ход (`AUTO FLIP`), или оставить её как есть (`FIXED`). Режим можно переключить в середине партии, позиция сохранится.

**Y → CONTROLS**: выбери действие, нажми **A**, затем нажми нужную кнопку (на пять секунд включается ожидание, `Esc` отменяет). Если кнопка уже занята другим действием, они меняются местами, поэтому ни одно действие не остаётся без кнопки. «RESET TO DEFAULT» возвращает стандартную раскладку. Раскладка лежит в `saves/controls.cfg`; кнопки на экране и в помощи показывают реальные назначения. Клавиши клавиатуры не меняются.

## Управление

По умолчанию (всё переназначается в игре, см. выше):

| RG35XX Plus | Действие |
|---|---|
| D-pad | Курсор на доске / выбор настройки |
| A | Выбрать фигуру, сделать ход, редактировать RGB |
| B | Отменить выбор или последний ход; закрыть настройки |
| X | Переключить 2D / 3D |
| Y | Открыть/закрыть настройки |
| Start | Новая партия |
| Select / H | Экран помощи |
| Menu | Выход |
| L1 / R1 | Поворот камеры |
| Q / E | Поворот камеры при тесте с клавиатурой |

## Установка на muOS (MustardOS)

### Способ 1 (рекомендуется): распаковать на карту

1. Скачай `ChessForge3D-manual.zip` на странице [Releases](../../releases).
2. Распакуй его в **корень SD-карты**, чтобы получилось `<SD>/MUOS/application/ChessForge3D/mux_launch.sh`
   (на телефоне: ZArchiver → «Распаковать в…» → сразу на карту; можно и на ПК).
3. Безопасно извлеки карту (иначе файлы могут записаться пустыми), вставь в консоль, перезагрузи.
4. Игра появится в **Applications → ChessForge 3D**.

### Способ 2 (экспериментально): Archive Manager

`ChessForge3D.muxapp` положи в `<SD>/MUOS/ARCHIVE/` и открой **Applications → Archive Manager**.
На MustardOS 2606.0 установка может блокироваться сообщением «Archive blocked»; причина не выяснена, тогда используй способ 1.

Файл `SHA256SUMS.txt` из релиза позволяет проверить, что архивы скачались без повреждений.
Stockfish (ARM64) лежит в `bin/stockfish`, его собирает CI. Настройки, сохранения и логи лежат в `ChessForge3D/saves/`.

## Нашёл ошибку?

Открой Issue и приложи `saves/run.log` (а для проблем с кнопками ещё `saves/input.log`: создай пустой файл `saves/input_debug`, понажимай кнопки), версию прошивки и модель консоли.

## Если кнопки не работают

Игра понимает геймпад (SDL GameController, запасной вариант — сырой joystick). **Menu/Guide** — выход.
Если A и B перепутаны — поставь `nintendo_layout=0` в `saves/input.cfg` (пример: `input.cfg.example`).
Для диагностики создай пустой файл `saves/input_debug`, понажимай кнопки и посмотри `saves/input.log`.

## Сборка ARM64

Проще всего через GitHub Actions (`.github/workflows/build.yml`, нативный ARM64-раннер).
Локально на ARM64 Linux с libsdl2-dev:

```sh
cmake -S . -B build-rg35xx -DCMAKE_BUILD_TYPE=Release
cmake --build build-rg35xx -j4
./scripts/package.sh build-rg35xx
```

## Тесты

```sh
cmake -S . -B build-tests -DCHESSFORGE_BUILD_TESTS=ON
cmake --build build-tests
./build-tests/chess_rules_tests   # правила шахмат
./build-tests/ui_tests            # переводы (все строки на всех языках, все символы есть в шрифте), кнопки, 3D-фигуры
```

## Как добавить язык или исправить перевод

Все строки лежат в `src/i18n.cpp`: одна строка таблицы на фразу, колонки идут в порядке языков из `Languages`. Встроенный шрифт 5x7 знает латиницу (без диакритики) и кириллицу; `ui_tests` сообщит, если в переводе есть символ, которого в шрифте нет. Новый язык: добавь его в `Languages`, увеличь `LanguageCount` в `i18n.hpp` и допиши колонку в каждую строку таблицы.

## Устройство 3D-фигур

`src/pieces3d.cpp`: модели собраны в коде (поверхности вращения, боксы, изогнутая трубка для головы коня) и один раз на каждый угол камеры отрисовываются в спрайты с освещением, контуром и сглаживанием. Каждый кадр рисуются готовые спрайты, поэтому это быстро даже на слабом процессоре.

## Совместимость

Проверялось на Anbernic RG35XX Plus с MustardOS 2606.0 Andromeda. На других устройствах и прошивках не тестировалось.

## Наборы фигур

В игре: **Y → PIECES** (влево/вправо) переключает набор для **2D-режима**. «BUILT-IN» это встроенные векторные фигуры. В 3D-режиме всегда используются встроенные 3D-модели.
Свои наборы кладутся в `pieces/<имя>/` (файлы `wP.bmp … bK.bmp`, подробности в `pieces/README.md`).
Релизная сборка включает набор `cburnett` с Lichess (автор Colin M.L. Burnett, лицензия GPLv2+). У других наборов Lichess лицензии разные, часть из них некоммерческие: смотри [COPYING.md](https://github.com/lichess-org/lila/blob/master/COPYING.md) в репозитории lila перед тем, как их распространять.
